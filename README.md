🚀 Mini Projetos em Python & Flet

Coleção de interfaces gráficas interativas desenvolvidas em **Python** utilizando a biblioteca **Flet**. O projeto reúne telas introdutórias para a prática de manipulação de estado, estruturação de layouts e gerenciamento de elementos em tempo real.

## 📱 Telas do Projeto

* **Controle de Itens (Congelamento):** Gerenciador dinâmico de itens que permite adicionar produtos à lista, alterar quantidades individualmente com botões de incremento/decremento (`+` e `-`) e remover itens com o botão de lixeira.
* **Contadores e Formulários:** Interfaces para entrada de texto, validação simples de formulários e atualização de elementos visuais na página.
* **Componentes de Layout:** Prática com `Row`, `Column`, `Container`, botões e personalização de temas escuros (*Dark Mode*).


## 🛠️ Tecnologias Utilizadas

| Tecnologia | Descrição |
| --- | --- |
| **Python 3.x** | Linguagem de programação principal |
| **Flet** | Framework de UI construído sobre o Flutter para Python |

## ⚙️ Como Executar o Projeto

### 1. Pré-requisitos

Tenha o Python instalado na versão 3.8 ou superior.

### 2. Instalar o Flet

Instale a biblioteca do Flet via terminal executando:

bash
pip install flet

### 3. Executar o Código

Navegue até a pasta do projeto e rode o arquivo desejado:

bash
python main.py
